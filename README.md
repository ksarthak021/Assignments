# Northline Press

Marketing site for **Northline Press** — a premium laundry and garment-care brand. Built with Vite, React, and TypeScript.

## Design direction

Soft celadon and mist greens on a light paper ground, with Cormorant Garamond for brand display and Figtree for body copy. Full-bleed hero photography, editorial section layouts, and restrained entrance/scroll motion — calm atelier energy, not a dashboard.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start the Vite dev server |
| `npm run build`   | Typecheck and production build |
| `npm run preview` | Preview the production build |
| `npm run lint`    | Run oxlint               |

## Stack

- Vite + React 19 + TypeScript
- CSS custom properties (no UI framework)
- Unsplash imagery for laundry / garment atmosphere
